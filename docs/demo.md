# 青溪试游

这是 game007 的自由江湖概念演示。从无名客开始，在青溪镇谋生、练武、结交与冒险，用可玩的规则检验人物根基、行动代价和世界后果。

## 打开

```bash
npm run dev -- --port 5174 --strictPort
```

访问 `http://localhost:5174/demo.html`。原版标题页也有「青溪试游」入口。打包后 `dist/demo.html` 与原版入口并存，支持子目录部署。

也可以运行 `npm run demo:export` 生成 `dist/qingxi-demo.html`。这份文件内置脚本、样式与图片，下载后用浏览器打开即可试玩，无需服务器或联网；默认「留白」和旧三种界面也能在文件内直接切换。单文件版的进度取决于浏览器对本地文件存储的支持，与服务器版本不互通。

## 手机界面

当前演示以手机竖屏为主，所有设备都使用最大宽度 480px 的单列游戏画面。主要导航留在底部，人物、去路与行动按钮提供至少 44px 的触控区域；战斗继续使用原有卡片布局与即时回合节奏。

默认「留白」使用现代无衬线字、简洁线条与留白，不使用水墨、卷轴或印章装饰。主屏集中呈现地点和附近人物，不自动选择人物，也不常驻展开人物资料与动作列表。点人后从底部打开交互抽屉，再选择交谈或行动；做完会在抽屉内显示回应。完整状态、记事与根基按需展开，不占满探索画面。

底部导航是「附近／行路／我」：附近找人或展开当地行动，行路查看地点与赶路成本，「我」查看状态并进入武学、行囊。可用动作保留成本与后果说明，不可用动作收在「尚不可做」中，展开可见缺少什么条件。重伤、精力不足、被拦查等处境保留必要提醒与可行出路；减少常驻文字不会取消行动代价或限制自由选择。首次选出身也压缩为简短列表，点选后再看该出身的说明，四种来处仍从零武学开始。

可直接访问 `/demo.html?layout=focus`。已有界面偏好会保留；通过「设置 → 界面对比」可切换留白和以下旧版方案。所有界面使用同一份人物与世界进度，切换、点人、展开抽屉和阅读信息都不推进时间，也不代替玩家执行行动。旧版仍保留顶栏「界面」入口。

| 方案 | 从哪里开始操作 | 直接打开 |
|---|---|---|
| 留白 · 默认 | 附近人物一屏呈现，点人展开底部抽屉；状态、根基、行动和记事按需查看 | `/demo.html?layout=focus` |
| 场景探索 · 旧版 | 山水场景内直接点人物，查看其回应与可选做法；路牌显示去向和步行时间，景物细节按需展开 | `/demo.html?layout=cards` |
| 事务总览 · 旧版 | 先看船工风波、已查证据和未完事项，从对应入口继续；再看眼下可办、当地人物与其他选择 | `/demo.html?layout=scroll` |
| 情境操作 · 旧版 | 顶部集中显示时辰、钱、精力与气血；眼下建议说明可做什么，底部「找人／做事／动身」便于拇指跳转 | `/demo.html?layout=compact` |

事务入口会区分**行路**与**查访**：人在渡口时点「长街查账」，先按标出的时间走到长街；到达后，再按当地查账动作的时间成本核对货单。点人物名字只选择交往对象，交谈、花钱担保或动武仍各有自己的按钮。快捷导航负责把相应操作带到眼前。

旧版的「眼下可办」与「眼下建议」依据世界规则筛选当前可执行的选择，最多三条，并为每条显示理由、时间和资源代价。被拦查时先给认罚或随捕头查问的办法；气血不足时提示敷药或免费歇脚；精力不足时根据当地条件与盘缠提示吃面或休息。平时则按已有线索、所学武功、出身和现场人物，提供查事、谋生或习武的入口。「留白」将合适的行动优先排列在行动抽屉中，仍保留其他做法。

建议会计算赶路后的时辰与人物是否仍在，临近午时递交证据会考虑许青的押送，夜里不会把请教指向已经离开的顾行舟。查看这些建议只整理信息，点击具体行动才按相同的世界规则结算；其他合法做法仍保留在人物和当地行动中。

## 建议体验

- **先选来处：**第一次打开先选渡口脚夫、山路信使、落第书生或武馆杂役，再进入青溪镇。四种出身都还不会武功，带着二十八文、一包行李和一包伤药起步；内功、剑术、轻功、内力与历练均为零。
- **先活下来：**选渡口脚夫，替陶三搬货挣盘缠。去长街买药、投店休息，或什么闲事也不管，去旧武场看看顾行舟。
- **拿钱换人情：**搬货后找卫衡，出六十文担保许青。去茶棚找获释的许青，看看他怎样回应。
- **靠见识解围：**在「设置 → 重新开始」选落第书生，再点一次确认；旧版可从人物页「换一种起步」进入。查长街运货账、问茶棚船客，再回去拿证据说话。悟性影响查账时间。
- **学会第一招：**在旧武场「看一遍收剑」，二十分钟后可向顾行舟分别请教渡水剑、养息功和穿巷步，顺序自选。每门花十五分钟与十点精力，不收银钱或历练。初学剑术得到练习木剑，初学内功生出三十点内力；学会之前，不能靠静修凭空练出武功。
- **试一回任性：**学过轻功后轻身带人走，学过剑术后拔剑救人。目击与交手留下追缉、名声、各自的人情。追缉达到 35 时，穿过长街或公所会被捕头拦查。可以认罚、接受查问；会剑术的人还可继续动武。不会武功也始终能走查证、担保等路线。
- **以武会友：**学会剑术后在旧武场切磋，再逐步体会内功、轻功与守中、逐流两种路数。首次重招等你看清才继续，之后有八秒应对时间，逾时自动选择当前成算最高的可用应对。打完消化历练，观察武学与根基的实际作用。

押送在游戏时间午时发生。赶路、修炼与休息推进时间，阅读与离线不会；错过渡口仍可到镇公所继续处理。没钱时能免费歇脚，接受查问也不要求最低钱数或气血，失败后仍能继续。

## 范围与基础规则

六处地点、八位人物、四种同总点数的出身、五项根基、三门需要亲自学会的入门武学、两种剑路，以及一桩可用证据、金钱、轻功、武力处理的风波。武馆杂役只站过基本桩，不预先掌握任何一门武功；出身影响生计和学武后的长处，不限制任务解法。当前 NPC 记忆与后续对话是有限规则；尚未实现完整江湖的门派、产业、动态事件链或长期经济。

武学升阶与行动耗时为短时试玩尺度，不能据此推定正式版长期成长曲线。火候上限六层表示这几门入门功夫的试玩边界。战斗复用原版对拆内核，衍生战斗公式集中在 `src/demo/battle.ts`，世界、资源与时间规则在 `src/demo/model.ts`，处境建议在 `src/demo/suggestions.ts`。建议的合法性与行路耗时使用现有世界规则，训练报价与实际扣除使用同一函数。

进度只存本机 `game007-sandbox-demo-v1`，明暗主题使用 `game007-sandbox-demo-theme`，界面偏好使用 `game007-sandbox-demo-layout`。不读取、修改原版存档，也不调用云存档。已有演示进度继续保留，包括此前已学的武功和旧铁剑；想体验零武学开局，可在「设置 → 重新开始」选择出身，再次点击确认，旧版也可从人物页「换一种起步」进入。战斗中刷新会从交手前状态重开当前一战，已经使用的伤药仍扣除；逐回合续战尚未实现。

旧版的淡彩水墨场景保存在 `public/demo/harbor.webp`，六处地点暂用同一张青溪山水，不代表最终场景美术。「留白」的探索主屏不使用这张水墨场景。

## 验证

```bash
npm run check
npm run build
npm run demo:smoke
npm run focus:smoke
npm run ux:smoke
```

`demo:smoke` 使用真实 Chromium 验证选出身、零武学开局、首次请教、两种救人路线、战斗与修炼、拦查的低资源出路、刷新续玩、存档隔离，以及旧三个界面和明暗主题。拦查与疗伤边界使用测试存档注入，其余主要路线通过真实点击推进。可用 `SMOKE_EXECUTABLE_PATH` 指定浏览器；默认优先系统 Chromium，其次 Playwright Chromium。

`focus:smoke`（`scripts/focus-smoke.mjs`）用于验证默认「留白」：五种视口尺寸下的主屏与触控、点人打开抽屉、关闭后的焦点返回、状态与其他页面按需访问，以及低资源和拦查时的可行出路。同时检查阅读、开关抽屉与切换界面不推进游戏时间，行动前能看到成本，行动后能看到回应。

`ux:smoke` 验证旧三种操作方案的实际入口：点场景人物并选择行动、从事务证据入口行路后再查访、使用情境建议与拇指快捷导航。检查同一存档切换与阅读不耗时，建议按钮的理由和代价可见，低血有药、无钱缺精力、巡街拦查、零武学请教、证据齐全和获释后领礼等处境能得到可执行的选项。状态边界使用测试存档注入，点击后核对世界的真实变化。

手机布局验收使用 320×568、360×560、390×844、430×932 竖屏与 720×560 矮宽视口，检查横向溢出、触控区域至少 44px、按钮是否被遮住、底部导航和明暗主题；玩法验收另检查战斗应对与撤离操作。大屏仍保持手机画面宽度，不另排桌面侧栏。

本云环境的浏览器管理策略禁止 `file://`。单文件导出在本地 HTTP 服务下检查内置资源、交互与存档；直接打开本地文件的行为无法在这个云浏览器中验收。

```bash
node scripts/demo-smoke.mjs http://127.0.0.1:5174/demo.html /tmp/game007-demo-qa
node scripts/focus-smoke.mjs http://127.0.0.1:5174/demo.html /tmp/game007-focus-qa
node scripts/ux-smoke.mjs http://127.0.0.1:5174/demo.html /tmp/game007-ux-qa
```
