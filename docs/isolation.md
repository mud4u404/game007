# game007 独立创作说明

game007 是公开的开发测试仓库，复制自 game006 提交 `72c77fd30fdd07a1593be165ba366519d157d51a`，保留此前 Git 历史。它使用独立检出、Git 对象和 origin，不配置回指来源项目的 upstream，也不自动合并来源项目的后续改动。

## 开发与存档

- 当前只使用本机存档及手动导入、导出，不提供云账号入口，不启动云同步。
- 原 Supabase 地址和公开密钥已清空；云端体检脚本与定时工作流已移除。
- 存档、备份和预留的云会话使用 `game007-` 名称，不读取、迁移、覆盖或清理来源项目的浏览器存储。两个 Pages 站点即使同源也不会串档。
- 保留原有存档码格式，可由用户主动导入；不会自动搬运旧存档。
- 保留的云模块及其模拟测试不接入游戏入口，也不连接真实后台。

## 协作与发布

- 用户直接在 game007 布置后续创作任务。来源项目的 Issue、PR、角色分工和例行审查均不自动继承。
- 自动接任务脚本只允许 origin 为 `mud4u404/game007`，否则退出。
- CI 针对当前仓库运行检查。Pages 默认不部署；以后需要时，在 game007 设置 Pages 为 GitHub Actions，并设置仓库变量 `ENABLE_PAGES=true`。
- 不复用来源项目的服务、密钥、Webhook 或定时任务。

## 验证

执行 `npm ci`、`npm run check`、`npm run build`，再运行浏览器冒烟测试。存储回归应证明旧项目数据不被读取或改写；冒烟测试应验证没有云账号入口，并走到首领战结算。
