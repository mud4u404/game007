# game007 · 江湖夜雨（独立创作）

> 「桃李春风一杯酒，江湖夜雨十年灯。」

这是从 game006 复制的公开开发测试项目，保留原始 Git 历史，后续创作仅在 game007 开展。云存档已停用，浏览器存档使用独立名称；来源仓库的任务与服务不继承。见 [独立创作说明](docs/isolation.md)。

一款**单机、手机竖屏、全程点按操作**的中文文字武侠游戏。玩家扮演一名身世成谜的少年侠客，在一个持续运转的江湖里自由闯荡。

- 可以追查身世，也可以把主线放在一边。
- 可以参军、投身六扇门、走镖、拜入门派，也可以自立门派。
- 江湖里的恩怨情仇、神兵绝学、红颜兄弟，都靠玩家自己去撞见、去争取。

## 已经定下的方向

| 方面 | 决定 |
|---|---|
| 形态 | 单机；手机浏览器打开即玩（H5），竖屏 |
| 操作 | 点按和菜单，不需要输入指令；重复劳作交给挂机和闭关 |
| 自由度 | 有主线，但可以不做；世界要大，处处有地方可去 |
| 界面 | D「素白卡片」风格：清爽、层级分明，支持浅色和深色 |
| 战斗 | 即时回合，配金庸式文字；见招拆招按「以己之长」计算成算；另有破绽、攻守之势、运功、绝招题字、伤势图和战后说书 |

## 开发

需要 Node.js 22 或以上。

```bash
npm install
npm run dev        # 本地运行，手机和电脑在同一网络下可以直接打开显示的地址
npm run check      # 类型检查与全部测试（含内容校验）
npm run build      # 打包到 dist/
npm run smoke      # 冒烟测试：无头浏览器从标题画面一路玩到首领战
```

技术栈：Vite + TypeScript，不依赖任何界面框架；测试用 Vitest。

**内容都是数据。** 地点、人物、对话、任务、对手、剧情都写在 `src/content/packs/` 下。
- 新增内容只需新建一个内容包文件。
- 校验测试会检查引用、通路、兜底回应和禁用名字。

## 协作方式

1. **独立创作**：用户直接在 game007 布置需求；不继承来源项目的任务、维护者分工或每日审查。
2. **先验证再交付**：运行类型检查、全部测试、构建和浏览器冒烟测试；所有后续分支与 PR 只属于 game007。
3. **自动化按需启用**：保留的 Issue 自动模式只有用户明确要求时才使用。Pages 仅在本仓库完成设置并启用 `ENABLE_PAGES` 后部署。
